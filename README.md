# nonebot-plugin-longge-tools

龙哥工具箱 - NoneBot2 插件，集成积分系统、宠物养成、钓鱼系统、以图搜图、AI 对话、生活工具等功能。

> 📌 完整指令总表见 [COMMANDS.md](./COMMANDS.md)

## 项目架构

```
nonebot_plugin_laofei_tools/
├── __init__.py              # 主入口：lg帮助指令、定时任务、启动初始化
├── config.py                # 共享配置：群聊开关、数据目录
├── CHANGELOG.txt            # 更新日志（lg公告自动读取）
├── image/                   # 静态图片资源（抽签签文图、宠物图、商品图）
├── common/                  # 通用模块
│   ├── points_commands.py   # 积分系统指令（签到、抽签、积分查询、新手大礼包）
│   ├── points_data.py       # 积分数据管理、银行利息、抽签逻辑
│   ├── lottery_pool.py      # 幸运奖池系统（暂未启用）
│   ├── ai_chat.py           # AI 对话（DeepSeek，@触发）
│   ├── life_utils.py        # 生活工具（天气、汇率换算、公告图片）
│   ├── restart.py           # 重启 bot 功能
│   ├── rest_mode.py         # 休息 / 静默模式
│   ├── data_utils.py        # 公共数据工具
│   └── utils.py             # 公共工具函数（图片下载等）
├── pet/                     # 宠物模块
│   ├── pet_commands.py      # 宠物系统全部指令
│   ├── pet_data.py          # 宠物数据管理、体力 / 经验 / 属性
│   ├── fishing_commands.py  # 钓鱼系统指令
│   ├── fishing_data.py      # 钓鱼数据管理（36 种鱼图鉴）
│   └── shop_image.py        # 商店图片生成
└── search/                  # 搜图模块
    ├── commands.py          # 搜图指令、管理指令、重启通知
    └── soutubot.py          # soutubot.moe API 客户端
```

## 安装

```bash
pip install nonebot-plugin-longge-tools
```

在 bot 入口（如 `bot.py`）加载插件：

```python
nonebot.load_plugin("nonebot_plugin_laofei_tools")
```

## 功能一览

### 积分系统

| 指令 | 别名 | 权限 | 说明 |
|------|------|------|------|
| `签到` | 打卡、积分签到、日常签到 | 全员 | 每日签到获取积分和经验，连续签到有加成 |
| `积分` | 查积分、我的积分 | 全员 | 查看自己的积分 / 等级 / 签到信息 |
| `抽签` | 今日运气、今日抽签、今日气运 | 全员 | 每日抽签（撞大运概率 2%），带签文图 |
| `新手大礼包` | 领取新手大礼包 | 全员 | 一次性领取 500 积分 + 所有食物各 1 个 |
| `转账 积分 @某人` | 转积分、给积分 | 全员 | 将积分转账给群友（仅群聊，需积分系统开启） |
| `积分排行` | 排行榜、今日排行 | 全员 | 查看积分 TOP10 排行榜（身上积分 + 银行积分） |
| `开启积分` | — | 超管 | 开启本群积分系统 |
| `关闭积分` | — | 超管 | 关闭本群积分系统 |
| `发积分 数量 [@某人\|全体]` | — | 超管 | 超级用户发放积分，支持单人（@ 或自己）或全体 |

> 以下功能为代码保留但暂未启用：银行存取、抽奖、猜数字、PK 对战、打劫、押注、奖池等。

### AI 对话（基于 DeepSeek）

| 指令 / 触发方式 | 别名 | 权限 | 说明 |
|------------------|------|------|------|
| `@机器人 + 问题` | — | 全员 | AI 问答，支持引用消息作为上下文（需群内先开启） |
| `lg清记忆` | lg清空记忆、lg清除记忆、lg forget | 全员 | 清除当前用户的对话历史 |
| `开启AI` | 开启ai、开启lgai、启用AI、启用ai | 超管 | 开启本群 AI 功能 |
| `关闭AI` | 关闭ai、关闭lgai、禁用AI、禁用ai | 超管 | 关闭本群 AI 功能 |
| `AI拉黑 @用户` | ai拉黑、lgai拉黑 | 超管 | 将用户加入 AI 黑名单（支持 @ 或 QQ 号） |
| `AI解除 @用户` | ai解除、lgai解除、AI取消拉黑、ai取消拉黑 | 超管 | 将用户移出 AI 黑名单 |

## 配置

在 `.env` 文件中添加：

```env
# 可选：配置默认开启搜图的群聊列表
LONGGE_SEARCH_ENABLED_GROUPS=["123456789", "987654321"]
```

超级用户与 AI 配置请参考 NoneBot2 官方文档（`SUPERUSERS`、`deepseek` 相关环境变量）。

## 数据存储

插件数据存储在 `data/laofei_tools/` 目录下：

| 文件 | 说明 |
|------|------|
| `user_points.json` | 用户积分、签到、抽签数据 |
| `pets_data.json` | 宠物数据（体力 / 经验 / 属性 / 背包） |
| `fishing_data.json` | 钓鱼图鉴与鱼箱数据 |
| `guess_games.json` | 猜数字游戏数据 |
| `enabled_groups.json` | 已开启搜图的群聊 |
| `points_disabled_groups.json` | 已关闭积分系统的群聊 |
| `ai_enabled_groups.json` | 已开启 AI 的群聊 |
| `ai_blacklist.json` | AI 黑名单用户 |
